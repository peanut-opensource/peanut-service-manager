# 花生服务管理器 · Peanut Service Manager

面向 macOS 的本机服务管理软件，按「项目 → 环境 → 服务」组织进程，支持服务分组、共享资源登记与本地 MCP。

首版需求已于 2026-10-17 确认，见 [完整需求](docs/requirements.md)。当前只有项目文档，尚未开始应用开发，没有可安装应用、MCP 实现或发布工作流。

## 已确认范围

- Swift 原生方案，最低支持 macOS 12，兼容 Intel 与 Apple Silicon。
- 项目、环境、分组及服务管理；同一服务可以加入多个分组。
- 单个及批量启动、停止、重启，自动更新状态与近期日志。
- 服务配置包含名称、工作目录、启动命令或脚本、说明、环境变量及本机运行时版本选择。
- 应用登录后自动启动、服务随应用启动、菜单栏入口及可配置快捷键；默认同时按住 `Option（Alt）+S+L`。
- MySQL、Redis 等资源可共享，按项目和环境绑定，支持数据库测试连接。
- PHP、Node.js 及其他资源支持类型和版本登记，不下载安装资源。
- Docker 首版只登记已有容器并检查状态，不管理容器启停、重启或日志，不创建容器、不下载镜像。
- 随应用提供本地 STDIO MCP，覆盖界面能力；普通列表隐藏秘密，独立工具可读取已绑定资源的凭据。
- 提供快速安装方式。

例如 Peanut Admin 可按开发、生产环境分别配置后端、租户后台、平台后台、PC 前端、H5 前端、外部产品文档站和内部文档站。

项目、环境、分组、服务、资源分别使用稳定 ID。MCP 显示完整目标路径；同名匹配到多个目标时返回候选并要求明确目标，不自动选取第一个。

首版不管理远程主机进程，不处理服务启动依赖，不保存历史日志。完整行为及边界以 [需求文档](docs/requirements.md) 为准。

## 开发与发布

- `dev`：日常开发及默认分支，本地主目录保持检出此分支。
- `main`：稳定分支，推送时生成预览版。
- 版本 tag：生成正式版。
- 安装包、构建方式、签名、公证及更新机制留待对应实施前确定；上述发布规则尚未实现。

项目实际运行资源见 [资源登记](docs/resource-registry.md)，安全问题见 [安全说明](SECURITY.md)。应用用户登记的私人资源及凭据不写入此公开仓库。许可证为 [MIT](LICENSE)。
