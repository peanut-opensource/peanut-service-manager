# 花生服务管理器 · Peanut Service Manager

面向 macOS 的本地服务管理软件，按「项目 → 环境 → 服务」组织进程。

当前仅完成项目初始化，尚无可安装的应用或 MCP 服务。

## 已确认范围

- 管理项目、环境及服务，环境支持开发、生产及自定义名称。
- 服务配置包含名称、工作目录、启动脚本和说明。
- 启动、停止、查看日志，自动更新状态与日志。
- 优先优化 macOS 原生体验，支持菜单栏入口、点击快速显示和可配置快捷键。
- 默认快捷键意图为 `Alt+S+L`，具体按键序列语义待设计确认。
- 提供 MCP 功能和快速安装方式。

例如 Peanut Admin 可按开发、生产环境分别配置后端、租户后台、平台后台、PC 前端、H5 前端、外部产品文档站和内部文档站。

项目、环境、服务分别使用稳定 ID。MCP 显示完整的「项目 / 环境 / 服务」路径；同名匹配到多个目标时返回候选并要求明确目标，不自动选取第一个。

生产环境也属于管理范围。当前已确认的是本机进程管理，尚未确认远程主机管理。

## 开发与发布

- `dev`：日常开发及默认分支，本地主目录保持检出此分支。
- `main`：稳定分支。
- 自动发布目标：推送 `main` 或版本 tag 时触发发布。
- 语言、框架、构建方式、两类发布的产物与渠道、签名及更新机制待确定，当前未启用发布工作流。
