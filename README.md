# 花生服务管理器 · Peanut Service Manager

面向 macOS 的本机服务管理软件，默认按「环境 → 项目 → 服务」浏览进程，支持服务分组和共享资源登记。

首版需求已于 2026-10-17 确认，见 [完整需求](docs/requirements.md)。

## 已确认范围

- Swift 原生方案，最低支持 macOS 12，兼容 Intel 与 Apple Silicon。
- 项目、可复用环境、分组及服务管理；项目与环境支持多对多关联，同一服务可以加入多个分组。
- 项目和环境均可作为关联入口；左侧导航的七个一级页面依次为服务列表（表格）、服务卡片、服务管理、资源列表、资源管理、MCP 服务和系统设置。
- 单个及批量启动、停止、重启，自动更新状态与近期日志。
- 服务配置包含名称、工作目录、启动命令或脚本、说明、环境变量及本机运行时版本选择；分别登记服务绑定 IP、端口和多个租户访问域名，预览并点击访问入口在默认浏览器打开。
- 应用登录后自动启动、服务随应用启动、菜单栏入口及全局快捷键；默认按 `Option（Alt）+Y` 显示窗口。
- MySQL、Redis 等资源可共享，按项目和环境绑定，支持数据库测试连接。
- PHP、Node.js 及其他资源支持类型和版本登记，不下载安装资源。
- Docker 首版只登记已有容器并检查状态，不管理容器启停、重启或日志，不创建容器、不下载镜像。
- 本地 MCP：应用内置 STDIO 服务端，可供 AI 客户端读取和管理项目、环境、分组、服务、资源与绑定；仅密码读取工具返回明文密码，并要求指定稳定资源 ID 及项目环境绑定。
- 提供快速安装方式。
- 工作区配置保存在本机 JSON，资源密码单独使用 AES-GCM 加密；本机加密 key 可在设置中明文查看和修改。设置页可导出或导入完整 JSON 配置，导入前验证格式和密码密文后替换现有配置。

例如 Peanut Admin 可按开发、生产环境分别配置后端、租户后台、平台后台、PC 前端、H5 前端、外部产品文档站和内部文档站。

项目、环境、分组、服务、资源分别使用稳定 ID。一个环境可关联多个项目；每个项目在该环境中的服务配置仍独立保存。MCP 显示完整目标路径；同名匹配到多个目标时返回候选并要求明确目标，不自动选取第一个。

MCP 配置方法、客户端配置片段和工具边界见 [本地 MCP 使用说明](docs/mcp.md)。

首版不管理远程主机进程，不处理服务启动依赖，不保存历史日志。完整行为及边界以 [需求文档](docs/requirements.md) 为准。

项目和登记信息以普通 JSON 保存在本机；只有资源密码单独加密，默认 key 为 `123456`，可在设置中查看和修改，key 明文保存在本机。应用不访问 macOS 钥匙串。应用登录启动项只在下次登录生效，避免变更开关时重复启动当前应用。

## 开发与发布

- 本地启动：`swift run peanut-service-manager`
- 打包可打开的 macOS 应用：`./scripts/package-app.sh`，输出到 `build/Peanut Service Manager.app`。
- 本机生产构建并安装：`./scripts/install-app.sh`，安装到 `/Applications/Peanut Service Manager.app`；后续更新替换应用包，不删除 `~/Library/Application Support/PeanutServiceManager` 中的配置。
- 当前本机验证版本：`0.0.1`。通用 `.app` 同时包含 Intel 与 Apple Silicon 二进制。
- 当前本机 `.app` 约 `2.6 MB`。打包先用 `lipo` 合并 arm64 与 x86_64，再对通用二进制执行 `strip -x` 移除本地符号；实测主程序约减少 `60%`，supervisor 约减少 `52%`。多尺寸 `AppIcon.icns` 为 `150 KB`，菜单栏 36 × 36 像素图为 `721 B`。
- `dev`：日常开发及默认分支，本地主目录保持检出此分支。
- `main`：稳定分支，推送时生成预览版。
- 版本 tag：生成正式版。
- `.app` 本机安装流程已提供；签名、公证、下载分发包及正式更新渠道留待后续实施。

项目实际运行资源见 [资源登记](docs/resource-registry.md)，安全问题见 [安全说明](SECURITY.md)。应用用户登记的私人资源及凭据不写入此公开仓库。许可证为 [MIT](LICENSE)。
